# Experiment 1: Develop a Simple "Hello World" Android Application

## Aim

To develop a simple Android application that displays the text **"Hello World!"** using Kotlin and XML layouts.

## Objective

- Understand the Android project structure.
- Learn how Activities work.
- Design a basic user interface using XML.
- Run an Android application on an emulator.

## Technologies Used

- Android Studio Quail 2 Patch 1
- Kotlin
- XML Layout
- ConstraintLayout
- Android SDK 37

## Concepts Covered

- Android Project Structure
- Activity
- ConstraintLayout
- TextView
- String Resources

## Project Structure

```text
AndroidProject/
│
├── app/
├── gradle/
├── gradlew
├── gradlew.bat
├── settings.gradle.kts
└── build.gradle.kts
```

## Application Workflow

1. Launch the application.
2. Android starts `MainActivity`.
3. `activity_main.xml` is loaded.
4. The `TextView` displays **Hello World!**.
